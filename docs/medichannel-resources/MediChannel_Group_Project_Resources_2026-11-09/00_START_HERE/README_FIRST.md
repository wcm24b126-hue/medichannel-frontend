## Team integration caution

- The Git repository uses Next.js 16 with Tailwind CSS 4; existing HTML demos are **not** copy-and-paste production frontend pages.
- Group work should be committed only on the individual's assigned branch (for the user: `frontend-fahim`) with review by the leader. Do not bulk-commit this entire resource archive into the Next.js source without team approval.
- The group database schema in this pack is a *draft* from previous design work. It needs review by the database/backend owners, database execution, and rule/security testing.
- This is a **documentation/design collection**, not a working Next.js + Spring Boot + PostgreSQL project.
- The private/independent solo Track B database files were intentionally excluded from the **group project** package to avoid mixing independently authored and shared work.
- Use **fictional patient data** only. Do not put real medical information or secrets into sample HTML, documents or GitHub.
